# Markdown Reader keyboard shortcuts

| Keys | What it does |
| --- | --- |
| Ctrl + E | Formatted or source |
| Ctrl + S | Save (changes made in the source) |
| Ctrl + O | Open another file (or drop one on the window) |
| Alt + ← | Back to the page before, after following a link |
| Ctrl + + / Ctrl + − / Ctrl + 0 | Bigger, smaller, back to 100 % (Ctrl + wheel works too) |
| F5 | Read the file again |
| Ctrl + W, Ctrl + Q | Close (asks first about unsaved changes) |
