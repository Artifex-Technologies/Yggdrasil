# Sudoku keyboard shortcuts

| Keys | What it does |
| --- | --- |
| ← → ↑ ↓ or H J K L | Move between cells |
| 1-9 | Place a digit (a note, in notes mode) |
| 0, Backspace, Delete | Erase |
| N | Notes on or off |
| U or Ctrl + Z | Undo |
| Ctrl + Y or Ctrl + Shift + Z | Redo |
| Shift + H | Hint |
| P or Space | Pause (hides the board) |
| Esc | Leave brush mode |

Mouse: right-click a cell to erase it; right-click a digit on the pad for brush mode (each click on a cell places that digit).
