# The top bar, dock and their popups: keyboard shortcuts

**Any popup** (start menu, calendar, Fylgja, a top bar card, window zones): Esc closes it.

**Start menu** (Win): typing goes to the search box from anywhere.

| Keys | What it does |
| --- | --- |
| Enter | Open the first search result |
| Backspace, Delete | Delete a letter (Ctrl + Backspace: a word; over a selection: all of it) |
| Ctrl + A | Select what was typed |

With the Folders start menu (Settings > Appearance > Start menu > Theme) also:

| Keys | What it does |
| --- | --- |
| ↑ / ↓ | Move through the results, the list or the power choices |
| Tab | Search → list → power choices |
| → / ← | Into a folder's apps / back out |
| Enter | Open the selected app, folder or power choice |

**Keyboard shortcuts card** (Win + /): any key or click closes it.

**Log out / restart / shut down countdown:** Enter goes ahead now, Esc stops it.

**Snap Assist** (after a window goes into a zone): ← → ↑ ↓ or Tab move between windows, Enter places the selected one, Esc stops.

**A top bar card with a search field** (Authenticator, Weather's place search): typing goes to the field, Enter does its search or
copies the first match, Backspace deletes.

**Window zones:** hold Super and drag a window to the notch, or Win + Shift + Z for the window in front; Esc cancels.
