# Lock screen, login screen and screenshots: keyboard shortcuts

**Lock screen:** type your password, Enter unlocks, Backspace deletes a letter, Esc clears what was typed.

**Login screen:** the same, plus Tab or ↓ / Shift + Tab or ↑ for another user (while nothing is typed) and F2 for another session.

**Screenshot** (Print Screen or Win + Shift + S; the screen freezes first):

| Keys | What it does |
| --- | --- |
| Drag | An area |
| Click | The window under the pointer (the whole screen where there is none) |
| Enter | The whole screen the pointer is on |
| Esc or right-click | Cancel |
