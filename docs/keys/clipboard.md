# Clipboard (Win + V) keyboard shortcuts

Typing goes to the search line.

| Keys | What it does |
| --- | --- |
| ↑ / ↓ | Move through the list |
| Enter | Copy the item and close |
| Shift + Enter | Copy and paste it into the window you came from (on Hyprland) |
| Tab | Switch between History and Snippets |
| Delete (with an empty search line), Ctrl + Delete | Remove the item |
| Ctrl + P | Pin or unpin it |
| Ctrl + E | Edit the snippet |
| Ctrl + N | New snippet |
| Esc | Close (in the snippet editor: cancel) |
| Ctrl + S | Save the snippet (in the editor) |
