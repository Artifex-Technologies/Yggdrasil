# Color Picker (Win + Shift + C) keyboard shortcuts

The screen freezes and a magnifier follows the pointer.

| Keys | What it does |
| --- | --- |
| ← → ↑ ↓ | Move one pixel |
| Mouse wheel | Zoom the magnifier |
| Click or Enter | Pick the colour (copied in the format chosen in Settings) |
| Esc or right-click | Cancel |
